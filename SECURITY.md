# Security

Please report a vulnerability privately, not in a public issue: email rouzbeh@deadpixelstudio.io, or use **Report a vulnerability** under this repository's **Security** tab. Say what you found, how to reproduce it, and which version of the SDK it affects. You will hear back within a few working days. Fixes go into the newest release.

This covers the SDK in this repository. For ChatFrom itself, the web app at chatfrom.io and the chat page the SDK shows, write to the same address.
